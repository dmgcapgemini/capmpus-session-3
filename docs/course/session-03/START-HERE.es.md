# Empezar · Sesión 3

Extrae el ZIP completo en una carpeta nueva. Las sesiones anteriores ya están resueltas; hoy quedan cuatro talleres. Conserva tus proyectos y datos anteriores.

Abre `guia super rapida.md` en la raíz del ZIP. Prepara una vez con `bash scripts/setup.sh --storage sqlite` o `.\scripts\setup.ps1 --storage sqlite`; después usa `start.sh` o `start.ps1`. El script arranca juntos API, web y simulador FMS. SQLite es la opción predeterminada y no requiere Podman ni WSL; PostgreSQL es opcional.

En el proyecto inicial son normales los catorce fallos identificados en [workshop-tests.json](workshop-tests.json). Las demás pruebas, los tipos y el lint deben pasar. La recuperación de sesiones anteriores ya está implementada.

Lee [la introducción](INTRODUCTION.es.md) y sigue [los talleres](WORKSHOP.es.md). Puedes consultar también la [arquitectura de la sesión 3](../../../ARQUITECTURA-SESION-03.es.md). Si falla la preparación, consulta [la ayuda](AYUDA-ARRANQUE.es.md).
